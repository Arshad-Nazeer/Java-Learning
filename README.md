# ☕ Java Learning

A structured Java learning repository documenting my progress from Java fundamentals to object-oriented programming, file handling, generics, collections, multithreading, and mini-projects.

The repository is organized lesson-by-lesson, with each topic placed in its own package. Every lesson builds on the previous one while including practical examples and console applications.
